# Family photos

Every image in this folder (`.jpg`, `.jpeg`, `.png`, `.webp`, `.gif`, `.avif`) appears in the slideshow
in the history section of the home page, in file-name order.

To add photos on GitHub: open this folder, choose **Add file → Upload files**, drop the photos and commit.
The site picks them up as soon as GitHub Pages redeploys (about a minute). Deleting a file removes it.

Tips:
- Name files to control the order, e.g. `01-wedding-1965.jpg`, `02-nazareth-church.jpg`.
- Keep each photo under ~500 KB (about 1600 px on the long side) so the page loads quickly on phones.
